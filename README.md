Features:
- HTML comment/whitespace cleanup
- Inline CSS minification
- Conservative inline JavaScript minification
- External scripts/styles are left unchanged
- Generates self-contained protected/index.html
- No API, CDN, npm package, website, or internet required

Usage:
1 Put your own index.html in this folder.
```

cd HTMLHIDE
chmod +x install.sh
```
